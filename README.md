Objectives
Flapping-wing aerial vehicles (FWAVs) require lightweight, compliant, and highly 
coordinated mechanisms to achieve stable and efficient flight. Biological birds 
accomplish this through skeletal structures coupled with muscle–tendon systems that 
distribute actuation forces across multiple joints.
The primary objectives of this work are:
• To design a bio-inspired bionic wing based on fundamental avian wing 
kinematics
• To fabricate all structural components using additive manufacturing 
techniques
• To implement an electromechanical actuation system using servo motors
• To integrate a propulsion system using a BLDC motor for forward thrust
• To develop basic mathematical models for motion and force estimation
• To experimentally evaluate mechanical performance and feasibility

All components were designed using computer-aided design (CAD) software. The 
wing skeleton was divided into modular segments to simplify printing and 
assembly. Integrated channels were designed to guide strings used for motion 
transmission. Hinges and joint pins were designed to be printable without support 
material where possible. The Fusion 360 model incorporates:
• Parametric groove radii
• Symmetrical mirroring
• Integrated string channels
